Скачай .glb модели персонажей и положи сюда:
  - steve.glb
  - alex.glb
  - creeper.glb
  - enderman.glb

Где взять:
  1. Blockbench (https://blockbench.net) → создать скина → Export → GLB
  2. Sketchfab → поиск "Minecraft Steve" → скачать GLB
  3. Конвертировать OBJ/FBX в GLB через любой онлайн-конвертер
